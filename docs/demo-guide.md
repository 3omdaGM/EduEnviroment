# دليل عرض الباحث

هذه نسخة Frontend تجريبية بمحتوى draft وحفظ داخل المتصفح نفسه،ولا تنشئ حسابات حقيقية أو بيانات دراسة. أسماء فريق البحث والصفات والشعاران المعروضان قدمها المستخدم؛ وسائل الاتصال تنتظر الباحث. لا نشر عام مطلوب أو منفذ.

## التشغيل وتجهيز الحالة

من جذر المشروع،Node>=22.22.0:

```sh
npm ci
npm run build:demo
npm run preview
```

المعاينة المحلية `http://localhost:4173` على الجهاز المشغل. لإبقاء المنفذ5173 المعتاد: `npm run preview -- --port 5173`. تشغيل خادم في بيئة بعيدة لا ينشئ رابطًا خارجيًا؛ يحتاج توجيه منفذ/Web preview متاحًا. الدخول: بريد`demo@example.com` ورمز نصي معلن`DEMO`؛التسجيل يسمح باسم مستعار دون كلمة مرور.

ابدأ بملف متصفح تجريبي منفصل. افتح `/demo-tools` ثم «إعادة ضبط التجربة» واقرأ تأكيد استبدال التقدم قبل الموافقة. تحميل نسخة0.3يعرض تعذر الاستعادة بدل حذفها؛ استخدم الملف المنفصل أو reset الصريح لبدء0.4. الخروج لا يمحو البيانات،ولا reset خفي.

## سيناريو قصير أمام اللجنة

1. **الرئيسية والأهداف:** اعرض اسم البيئة كاملًا في الهيدر المختصر،ثم مقدمة الرسالة واسم الباحثة والمشرفين بالأسماء والصفات المقدمة من المستخدم. انتقل من الخيارات الستة في المنتصف،ومن قائمة التنقل على الهاتف. الدخول والخروج التجريبي في تذييل الصفحة. افتح أهداف البيئة:أربعة أهداف عامة من صورة المستخدم،ظاهرة كاملة في كروت بصفين على الكمبيوتر وعمود على الهاتف. الاطلاع متاح للجميع ولا يفتح محتوى مقفلًا. افتح الدليل لتوضيح الرحلة.
2. **القبلي وحد50:** ادخل بالتجربة. في `/demo-tools` اختر «مؤهل عند50%» وأكد،ثم تعليمات القبلي ← سجل المحاولات ← عرض النتيجة:10/20تفتح المسار. لتوضيح المقابل اختر «غير مؤهل فوق50%»:11/20تبقي التدريب مقفلًا. هذه نتائج مصطنعة للحالات،وليست قياسًا لمشارك.
3. **محتوى فعلي:** أعد «مؤهل عند50%»،ثم `/modules/mod-01/intro` ← الأهداف ← الدروس ← الدرس الأول. اقرؤوا جزأي المفهوم وكبّروا الرسم؛أقر الاطلاع ثم تقدموا بين العناصر. كل الأجزاء والعناصر متاحة بحرية؛اختر عنوان الجزء،وزر«تم الاطلاع»يسجل الاطلاع دون انتقال تلقائي أو قياس للفهم.
4. **النشاط والذاتي:** النشاط والذاتي متاحان مباشرة بعد التأهل دون اشتراط أحدهما للآخر. أجب عن السؤالين وسلم النشاط ولو بدرجة0. إن أردت الاختصار دون تغيير قواعد المتدرب،اختر حالة «درس غير مجتاز» من أدوات العرض:تحتوي إقرارات العناصر ونشاطًا مسلّمًا وذاتي0. افتح الذاتي وسجله لعرض عدم الاجتياز،ثم «محاولة جديدة».
5. **اجتياز50%:** في ذاتي الدرس الأول أجب عن مفردة واحدة صحيحًا من اثنتين وسلم. مفاتيح الباحث لهذه النسخة في الفقرة التالية،ولا يعرضها القبلي/البعدي في المنتج. ينتج1/2ويسجل إنجاز الدرس؛الدرس الثاني وبقية الدروس متاحة أصلًا بعد التأهل. أعد لاحقًا بدرجة أقل لتوضيح بقاء النجاح والنقاط وعدم تكرارهما.
6. **الموديولات التالية والبعدي:** جميع الدروس والموديولات متاحة بعد التأهل؛يمكن فتح Forms أوأي موديول مباشرة دون اجتياز سابق. للاختصار اختر «إكمال البيئة»،ثم راجع Forms والمشاركة والخصوصية،وTeams والصلاحيات،وMendeley والفرق بين المنتجين. افتح تعليمات البعدي وسلم محاولة أو اعرض السؤال وتأكيد التسليم؛لا شهادة ولا حكم اجتياز مخترع. الحالة المكتملة تعرض470XP وأربع شارات ومستوى4 منفصلة عن درجات الاختبارات.

في الذاتي الأول،الإجابة الصحيحة للسؤال الأول:«جمع تفسير قصير للحالة ومناقشة تبريراته». الصحيحة للثاني:«تحديد الهدف والمهمة ثم اختيار أداة متاحة وبديل مناسب». لإظهار50% اختر الأولى صحيحة وبديلًا آخر في الثانية. الترتيب المرئي ثابت،واستخدم نص البديل بدل حفظ موضعه. استعرض السجل والإجابات عبر السابق/التالي قبل التسليم؛المسلمة لا تعدل والإعادة محاولة جديدة.

## بناء المعاينة والحدود

`npm run build:demo` يجهز`dist/` بالمحتوى الكامل وأدوات الحالات الخمس. `npm run build` يستبعد صفحة الأدوات ورابطها وملفها؛كلاهما يظل frontend محليًا بمفاتيح مكشوفة تقنيًا،وليس نظام دراسة آمنًا. لا تستخدم `build:e2e` للعرض؛هو fixture مصغر لاختبار الرحلة. الاستضافة الثابتة لاحقًا تحتاج SPA fallback إلى`index.html` للروابط المباشرة،ولا يتطلب تجهيز البناء نشرًا عامًا.

للمراجعة: `docs/content-review.md` وقائمة المحتوى`docs/content-manifest.json`،والقرارات المعلقة في`docs/decisions.md`. التحقق والصور وحدود الأجهزة في`docs/progress.md`. المرحلة الخامسة وربط البيانات لم يبدآ.


### العرض المضغوط والأسئلة الأربعة

الدليل يصعد مباشرة تحت العنوان،مع اختيار الخطوة من القائمة على الهاتف وأزرارالسابق/التالي. الاختياراتأ/ب يمينًا وج/د يسارًا،ويمكن تغيير الإجابة قبل التسليم؛صح/خطأ اختياران فقط. افتح «تفاصيل الحفظ والتسليم والنتائج» أو «سجل المحاولات» من التعليمات،و«مراجعة إجاباتك والتفسيرات» في نتيجة النشاط/الذاتي. مراجع القراءة والرسم تحت «الرسم التوضيحي ومراجع القراءة»،وتقدم كل موديول وشاراته تحت «التفاصيل والتقدم». النصوص كاملة وقد تحتاج القراءة الطويلة للتمرير على الشاشات القصيرة.

تنبيه توافق:نسخة المحتوى0.4.1-draft بأربعة بدائل لا تستعيد محاولات0.4.0 أو0.3. لم تُحذف البيانات القديمة؛للتجربة استخدم ملف متصفح منفصلًا أو reset مؤكدًا في أدوات العرض داخلdemo بعد حفظ ما تحتاجه من التجربة السابقة. لا تنشئ حسابًا أو تدخل بيانات حقيقية.

### استعراض الموديول والتسليم قبل إجابة الجميع

من«المحتوى التعليمي» اضغط اسم الموديول أو«تفاصيل الموديول». المقدمة والأهداف وعدد وأسماء الدروس متاحة قبل التأهل،أما«فتح الدرس» فيعرض سبب القفل وخطوة التأهل المطلوبة إذا لم تتأهل. الاستعراض وحده لا يضيف تقدمًا أوXP. الكروت لها لونhover خفيف وglow،وتعرض القوائم كاملة دون أزرار تقسيم؛يمكن التمرير الطبيعي عند الضرورة كما أكد المستخدم. معلومات التقدم والتقويم والشارات من«تقدمك والتقويم».

زر«تسليم» موجود معالسابق/التالي فيشاشة السؤال. القبلي يقبل التسليم دون أي إجابة؛البعدي يحتاج5إجابات علىالأقل،والنشاط والذاتي يحتاجان السؤالين الحاليين كاملين. بعدإجابة5من20يمكن تركالباقي:تظهر رسالة عددالمتروك واحتسابه غيرصحيح،ثم«نعم،سلّم المحاولة» أوالعودة للأسئلة. مثال5إجابات صحيحة و15متروكة =5/20=25%،وليس100%. النتيجة تحفظ وتبقى بعدالتحديث؛المحاولة المسلمة لا تعدل. شرط أهلية القبلي<=50%والإنجاز الذاتي>=50%والمكافآت محفوظ؛الإنجاز لا يقيد فتح المحتوى بعد التأهل.

تعليمات الحفظ وسجل المحاولات والمراجع فينوافذ مستقلة،معصفحات للتفاصيل الطويلة. علىالهاتف والشاشة القصيرة يوجد العنوان الكامل للدرس والتنقل منزر«أقسام الدرس»؛المحتوى فيبطاقة القراءة. استخدم«التالي/السابق» داخل القوائم/النصوص لقراءة جميع الصفحات،ثمأقر بالاطلاع علىالجزء للانتقال إلىالجزء المنطقي التالي. لا قص أو إخفاء نص تعليمي لتقليل التمرير.

بقيت نسخة المحتوى 0.4.1-draft، وتستمر البيانات الكاملة المحفوظة لهذه النسخة؛ لم تتغير الأسئلة أو مفاتيحها، ولا يلزم reset لهذا التعديل. الحالات الأقدم 0.4.0/0.3 تظل محفوظة خامًا دون ترحيل خفي كما سبق.


## مراجعة التنقل الحر الحالية

اضغط رقم الخطوة في الدليل لعرضها؛كل الأرقام ظاهرة على الهاتف. أسماء المشرفين كلها ظاهرة مهما تغير حجم الشاشة دون أزرار تلقائية. لون الخلفية أزرق لبني والكروت بيضاء. التمرير الطبيعي عند الضرورة مقبول بتأكيد المستخدم؛لا قص نص أو تصغير غير مقروء.

لتجربة القبلي الفارغ:ابدأ تجربة ثم القبلي،اضغط«تسليم»دون اختيار،لاحظ التحذير من20سؤالًا متروكًا،ارجع للأسئلة للتأكد من عدم التسليم،ثم أكد. النتيجة0/20تفتح جميع الدروس والعناصر والتقويمات دون نقاط للقبلي. زر المراجعة قبل التسليم أزيل،والرابط القديم يعود للأسئلة. أدوات العرض تبقى فيdemoفقط.

فحص هذه الجولة: `npm run content:manifest && npm test && npm run lint && npm run build:demo && npm run test:open-learning`. فحص البناء العادي: `npm run build && npm run test:open-learning:production` ثم أعد `npm run build:demo` للعرض. الفحوص القديمة في مجلدات المراحل توثق قواعد التسلسل/المراجعة السابقة؛ الجولة الحالية لها suite وأدلة مستقلة في `review/open-learning`.
