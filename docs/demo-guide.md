# دليل عرض الباحث

هذه نسخة Frontend تجريبية بمحتوى draft وحفظ داخل المتصفح نفسه،ولا تنشئ حسابات حقيقية أو بيانات دراسة. أسماء فريق البحث والصفات المعروضة قدمها المستخدم؛ الشعارات الرسمية ووسائل الاتصال تنتظر الباحث. لا نشر عام مطلوب أو منفذ.

## التشغيل وتجهيز الحالة

من جذر المشروع،Node>=22.22.0:

```sh
npm ci
npm run build:demo
npm run preview
```

المعاينة المحلية `http://localhost:4173` على الجهاز المشغل. لإبقاء المنفذ5173 المعتاد: `npm run preview -- --port 5173`. تشغيل خادم في بيئة بعيدة لا ينشئ رابطًا خارجيًا؛ يحتاج توجيه منفذ/Web preview متاحًا. الدخول: بريد`demo@example.com` ورمز نصي معلن`DEMO`؛التسجيل يسمح باسم مستعار دون كلمة مرور.

ابدأ بملف متصفح تجريبي منفصل. افتح `/demo-tools` ثم «إعادة ضبط التجربة» واقرأ تأكيد استبدال التقدم قبل الموافقة. تحميل نسخة0.3يعرض تعذر الاستعادة بدل حذفها؛ استخدم الملف المنفصل أو reset الصريح لبدء0.4. الخروج لا يمحو البيانات،ولا reset خفي.

## سيناريو قصير أمام اللجنة

1. **الرئيسية:** اعرض اسم البيئة كاملًا في الهيدر المختصر،ثم الترحيب واسم الباحثة والمشرفين بالأسماء والصفات المقدمة من المستخدم. انتقل من الخيارات الستة في المنتصف،ومن قائمة التنقل على الهاتف. الدخول والخروج التجريبي في تذييل الصفحة. افتح الأهداف والدليل لتوضيح الرحلة.
2. **القبلي وحد50:** ادخل بالتجربة. في `/demo-tools` اختر «مؤهل عند50%» وأكد،ثم تعليمات القبلي ← سجل المحاولات ← عرض النتيجة:10/20تفتح المسار. لتوضيح المقابل اختر «غير مؤهل فوق50%»:11/20تبقي التدريب مقفلًا. هذه نتائج مصطنعة للحالات،وليست قياسًا لمشارك.
3. **محتوى فعلي:** أعد «مؤهل عند50%»،ثم `/modules/mod-01/intro` ← الأهداف ← الدروس ← الدرس الأول. اقرؤوا جزأي المفهوم وكبّروا الرسم؛أقر الاطلاع ثم تقدموا بين العناصر. يلزم جزءان لكل عنصر قبل النشاط؛الإقرار لا يثبت الفهم.
4. **النشاط والذاتي:** أجب عن السؤالين وسلم النشاط ولو بدرجة0؛يفتح الذاتي. إن أردت الاختصار دون تغيير قواعد المتدرب،اختر حالة «درس غير مجتاز» من أدوات العرض:تحتوي إقرارات العناصر ونشاطًا مسلّمًا وذاتي0. افتح الذاتي وسجله لعرض عدم الاجتياز،ثم «محاولة جديدة».
5. **اجتياز50%:** في ذاتي الدرس الأول أجب عن مفردة واحدة صحيحًا من اثنتين وسلم. مفاتيح الباحث لهذه النسخة في الفقرة التالية،ولا يعرضها القبلي/البعدي في المنتج. ينتج1/2ويفتح الدرس الثاني. أعد لاحقًا بدرجة أقل لتوضيح بقاء النجاح والنقاط وعدم تكرارهما.
6. **الموديولات التالية والبعدي:** الدرس الثاني ليس الموديول الثاني؛يلزم اجتياز دروس الموديول الأول الثلاثة لفتح Forms. للاختصار اختر «إكمال البيئة»،ثم راجع Forms والمشاركة والخصوصية،وTeams والصلاحيات،وMendeley والفرق بين المنتجين. افتح تعليمات البعدي وسلم محاولة أو اعرض السؤال والمراجعة؛لا شهادة ولا حكم اجتياز مخترع. الحالة المكتملة تعرض470XP وأربع شارات ومستوى4 منفصلة عن درجات الاختبارات.

في الذاتي الأول،الإجابة الصحيحة للسؤال الأول:«جمع تفسير قصير للحالة ومناقشة تبريراته». الصحيحة للثاني:«تحديد الهدف والمهمة ثم اختيار أداة متاحة وبديل مناسب». لإظهار50% اختر الأولى صحيحة وبديلًا آخر في الثانية. الترتيب المرئي ثابت،واستخدم نص البديل بدل حفظ موضعه. راجع السجل والمراجعة قبل التسليم؛المسلمة لا تعدل والإعادة محاولة جديدة.

## بناء المعاينة والحدود

`npm run build:demo` يجهز`dist/` بالمحتوى الكامل وأدوات الحالات الخمس. `npm run build` يستبعد صفحة الأدوات ورابطها وملفها؛كلاهما يظل frontend محليًا بمفاتيح مكشوفة تقنيًا،وليس نظام دراسة آمنًا. لا تستخدم `build:e2e` للعرض؛هو fixture مصغر لاختبار الرحلة. الاستضافة الثابتة لاحقًا تحتاج SPA fallback إلى`index.html` للروابط المباشرة،ولا يتطلب تجهيز البناء نشرًا عامًا.

للمراجعة: `docs/content-review.md` وقائمة المحتوى`docs/content-manifest.json`،والقرارات المعلقة في`docs/decisions.md`. التحقق والصور وحدود الأجهزة في`docs/progress.md`. المرحلة الخامسة وربط البيانات لم يبدآ.
