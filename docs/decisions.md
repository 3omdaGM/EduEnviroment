## اختيارات تنفيذ المرحلة الثانية

| ID | الاختيار والسبب |
| --- | --- |
| D09 | فرع محلي مستقل `phase-2-ui` مبني على commit المرحلة الأولى `fc6d325`، دون دمج PR المرحلة الأولى أو دفع المرحلة الثانية إلى GitHub تلقائيًا. |
| D10 | React/DOM `19.3.1`، Vite `8.3.4`، React Router `8.4.0` بوضع declarative من `react-router`، Tailwind `4.3.3` عبر Vite plugin و`@import`، Lucide `1.57.0`. الإصدارات الدقيقة في package/lock بعد مراجعة التوثيق الرسمي وpeer dependencies. TypeScript `6.0.3` لتوافق typescript-eslint `8.71.2` الذي يتطلب `<6.1`؛ لم يُفرض TypeScript 7 الخاص بفحص المرحلة الأولى على التطبيق. |
| D11 | لا مكتبة حركة أو primitives إضافية؛ CSS يكفي و`dialog.showModal()` يوفر حصر التركيز وEscape وإرجاعه للمشغّل، مع أسماء وأزرار إغلاق. Cairo محلي من Fontsource بترخيص SIL OFL محفوظ في `public/fonts/Cairo-OFL.txt`. |
| D12 | سيناريو معاينة ثابت يسمح بالموديول الأول/الدرس الأول فقط كما أجاز الطلب الأحدث، مع تنبيه صريح. ليس نتيجة قبلي مسلّمة ولا تغييرًا لقواعد أهلية الدراسة. العناصر تتتابع بإقرار في ذاكرة React فقط، دون نقاط أو إكمال درس. refresh يعيدها ويُذكر ذلك في الواجهة. |
| D13 | الهيدر sticky على الشاشات الواسعة، وفي التدفق الطبيعي على الهاتف لتجنب احتلال عنوان طويل معظم الشاشة. تنقل العنصر أسفل النص في التدفق الطبيعي مع safe area؛ أزيل sticky السفلي بعد ملاحظة تغطيته للرسم أثناء الفحص. |
| D14 | صفحات الحسابات تعريفية بلا حقول كلمات مرور، والتقويم/النشاط/الذاتي بأزرار معطلة وأسباب واضحة. لا إرسال بريد أو رسائل أو درجات أو أهلية أو إنجازات مزيفة. لا service adapter أو auth أو DB في هذه المرحلة. |
| D15 | محتوى قراءة قصير بصياغة عربية أولية للدرس الأول مع مرجع UNESCO ICT-CFT الرسمي وتاريخ وصول 2026-10-16 في بيانات التحرير؛ كل المحتوى draft. عناوين دروس الموديولات الأخرى لم تُختلق، وأهدافها مجرد اقتراحات موجزة غير معتمدة. |
| D16 | التحقق المحلي باستخدام Chromium المتاح وPlaywright وفحص axe الآلي، دون تنزيل متصفح جديد. صور المراجعة والتقارير في `review/phase-2/`. فحص التكبير الآلي يستخدم CSS zoom 200% مع نص أطول، وهو محاكاة موثقة لا ادعاء بجهاز هاتف حقيقي أو قارئ شاشة. |

مراجع الإعداد التي روجعت فعليًا في 2026-10-16: [React](https://react.dev/learn/creating-a-react-app)، [Vite](https://vite.dev/guide/)، [React Router declarative](https://reactrouter.com/start/declarative/installation)، [Tailwind Vite](https://tailwindcss.com/docs/installation/using-vite). قيم الحزم المؤكدة من سجل npm في اليوم نفسه، والـlockfile هو المرجع التنفيذي.

`DEMO_STUDY_POLICY` في `contracts.ts` يعلن `scope: 'demo-only'` و`preEligibilityAttempt: 'first-submitted-pre'`، مع البعدي والشهادة صراحة غير محسومين. هذا config توثيقي لا خدمة تعمل. اعتماد أي سياسة إنتاج يتطلب تحديثًا صريحًا للقرارات والعقد قبل تنفيذه.

## قرارات بحثية معلقة — لا موافقة مفترضة

| ID | المطلوب من الباحث قبل التطبيق الفعلي للدراسة | السلوك المؤقت في العرض |

| R01 | أي محاولة قبلي تحدد الأهلية عند الإعادة؟ | أول قبلي مُسلّم فقط؛ الباقي محفوظ مستقلًا. |
| R02 | أي محاولة بعدي تدخل التحليل؟ | حفظ جميع المحاولات دون وسم إحداها «المعتمدة للتحليل». |
| R03 | هل توجد عتبة للبعدي أو شهادة وشروطها؟ | نتيجة نسبة فقط؛ لا حكم اجتياز ولا شهادة. |

| R05 | اعتماد المحتوى والأسئلة والأهداف وأوزانها وأعداد/عناوين دروس الموديولات 2–4 وسياسة إجابة الكل. | draft موسوم في بيانات التحرير؛ لا اختلاق محتوى معتمد. |
| R06 | اعتماد نظام المحفزات والأسماء والنقاط والمستويات، والأسماء والأدوار والشعارات ووسائل الاتصال الفعلية. | بدائل واضحة ومقترحات قابلة للتهيئة؛ لا شعار رسمي مولد أو منصب مخمن. |

هذه القرارات لا تعطل توثيق المرحلة الأولى ولا تستلزم سؤالًا الآن. لا نفترض أن شرط الذاتي ينطبق على البعدي، ولا أن placeholder يمنح إذنًا بجمع بيانات حقيقية.
