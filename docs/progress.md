## ما أُنجز في الرابعة

- حصر المرفقات النصية الخمسة والأصول المتاحة: لا شعارات رسمية أو أسماء أو مناصب أو اتصال أو بنك أسئلة معتمد جديد. بقيت البدائل واضحة دون اختلاق بيانات أو صور شخصية.
- نسخة محتوى **0.4.0-draft**: أربع محطات بالترتيب المعتمد،9دروس(3/2/2/2)،18هدفًا قابلًا للملاحظة،29عنصرًا و58جزء قراءة قصيرًا: فكرة ثم موقف تطبيق. مقدمات وأهداف الموديولات والدروس مكتملة بالقوالب السابقة؛ أعداد وعناوين دروس2–4 مؤقتة.
- Forms يشمل المفردة والمفتاح والتغذية الراجعة والردود والمشاركة والخصوصية؛ Teams يشمل القنوات والمحادثات والاجتماعات وصلاحيات الموارد مع حدود الحساب وسياسات المؤسسة؛ Mendeley يميز Reference Manager لتنظيم المكتبة وcollections من Cite في Word للاستشهاد والنمط والقائمة. الأمثلة المهنية تربط المهارة بهدف تعليمي ولا تختبر حفظ موضع زر.
- أعيدت مراجعة **76مفردة**:20قبلي و20بعدي بتوزيع15MCQ/5صح وخطأ لكل منهما،وسؤالان نشاط وسؤالان ذاتي لكل درس. MCQ بثلاثة بدائل ومفتاح واحد وتفسير محدد. كل سؤال مرتبط بهدف وعناصر ومراجع في سجل التحرير؛ لا ادعاء تكافؤ نفسي أو إحصائي أو اعتماد باحث.
- المصادر الرسمية العشرة مفتوحة ومراجعة بتاريخ2026-10-16، وتاريخ الوصول والمنتج والمصدر في البيانات. النصوص التعليمية والأمثلة صياغة أصلية؛ لم تُنسخ صور أو فقرات طويلة من المواقع أو يُنسب فتح PDF غير متاح.
- سجل محتوى قابل للتوليد ومراجعة وبنود اعتماد، ودليل مختصر لعرض الباحث يشمل حد50 وعدم الاجتياز ثم الإعادة والانتقال للدروس/الموديولات والبعدي، واختصار المرور بالحالات الخمس المنفصلة دون تغيير قواعد المتدرب.
- ترخيص Lucide ISC/MIT مرفق مع Cairo OFL السابق؛ الرسوم SVG أصلية ذات أبعاد جوهرية ونص HTML وتكبير ميسر. لا صور نقطية جديدة تتطلب WebP/AVIF أو lazy loading. تم تهدئة ملاحظة المسودة وإزالة وصف حماية إنتاجية من تعليمات المتدرب؛ التفاصيل التقنية والبحثية في التوثيق.
- شروط الثالثة باقية: أهلية أول قبلي مُسلّم <=50%، اجتياز الذاتي >=50% قبل التقريب، إقرارات الأجزاء بالترتيب ثم نشاط مُسلّم بأي درجة، وعدم سحب النجاح السابق أو تكرار المكافآت. XP10نشاط/20درس/50موديول،470للمسار الكامل وأربع شارات ومستوى4، منفصل عن درجات التقويم. لا شهادة أو عتبة بعدي مخترعة.
- تغيرت الأسئلة والأجزاء، فارتفعت نسخة المحتوى والتقويم مع بقاء schemaالتخزين1. حالة0.3غير المتوافقة لا تُمسح أو تُرحّل تلقائيًا؛ تظهر رسالة ويظل النص الخام، ثم reset مؤكد داخل demo-tools أو ملف متصفح منفصل. لا كلمات مرور أو بريد/رمز مخزن ولا حسابات أو بيانات دراسة حقيقية.

## الملفات المؤثرة

- `src/data/course-content.ts` للمحتوى والأهداف والأمثلة، و`course-extension.ts` للمراجع والنسخة، و`catalog.ts` لتجميع القوالب، و`assessments.ts` للمفردات والمفاتيح وروابط الأهداف.
- `src/data/content-manifest.ts` و`docs/content-manifest.json` وسكربت التوليد `scripts/write-content-manifest.mjs`؛ لا مفاتيح تصحيح في manifest.
- `docs/content-review.md` للمراجعة والمصادر وحالة الاعتماد، و`docs/demo-guide.md` للتشغيل والعرض وإعادة الحالة. المواصفة والقرارات وAGENTS محدثة للرابعة.
- تعديل محدود لـ`AssessmentPage.tsx` و`illustrations.tsx` و`styles.css`؛ لا إعادة تصميم أو استبدال stack أو تعديل لقواعد المجال/adapter من الثالثة. حزم المشروع نفسها؛ package/lock يثبتان الإصدار0.4.0 دون إضافة dependencies جديدة.
- `content-review.test.ts` للتحقق من الترابط، و`phase4-ui.spec.ts` وإعدادات Playwright الخاصة بالرابعة. اختبارات الرحلة والبناء العادي من الثالثة يعاد تشغيلها مع البيانات الجديدة وتقارير منفصلة في `review/phase-4/`.

## التشغيل والعرض

```sh
npm ci
npm run content:manifest
npm run build:demo
npm run preview
```

المحتوى الكامل وأدوات الحالات الخمس في `dist/`؛ المعاينة على `http://localhost:4173` على الجهاز المشغل. للمنفذ5173 استخدم `npm run preview -- --port 5173`. لا يعني loopback في بيئة بعيدة رابطًا خارجيًا أو تحديث Web preview؛ يحتاج ذلك توجيه منفذ مدعومًا. لم تُنشأ استضافة عامة.

الدخول `demo@example.com` والرمز المعلن `DEMO`، أو اسم مستعار في التسجيل. راجع `docs/demo-guide.md` قبل العرض، وابدأ بملف متصفح منفصل أو reset مؤكد للحالة القديمة. `npm run dev` للتطوير؛ `npm run build` للبناء العادي دون أدوات العرض. الاستضافة الثابتة لاحقًا تحتاج SPA fallback إلى `index.html`.

## ما بقي

تزويد وسائل الاتصال واعتماد الباحث للمحتوى والأسئلة ومخططها وأوزانها وصدقها وأعداد دروس2–4 ونمط التوثيق وحسابات المنتجات وقيم المحفزات، وقرارات محاولة القبلي/البعدي والتحليل والشهادة. أسماء فريق البحث والصفات المعروضة قدمها المستخدم بعد الرابعة؛ لم تُخمن درجة الباحثة أو انتماؤها. مراجعة خبير وقارئ شاشة وأجهزة فعلية مطلوبة خارج حدود الفحص الآلي. النظام frontend تجريبي بمفاتيح مكشوفة تقنيًا؛ لا auth/API/Backend/DB أو حفظ عبر الأجهزة أو جاهزيةProduction. المرحلة الخامسة لم تبدأ.

## تعديل الهيدر والرئيسية بعد الرابعة

- طلب المستخدم تقليل السكرول بتقصير الهيدر وتوسيط الخيارات الستة، وحذف سطر الجامعة/الكلية والكلام الإضافي منه. العنوان الكامل محفوظ،وموضعا الشعارين الحاليان بلا نصوص ظاهرة إضافية،مع اسم ميسر لكل رمز. الدخول والخروج التجريبيان في التذييل؛ التنقل والتقويم وقائمة الهاتف مستمرون.
- حُذفت رسمة الرئيسية والنبذة والأزرار الزائدة؛ بقي ترحيب قصير،ثم الباحثة سلوى نبوي غنيم والمشرفون عبدالعزيز طلبة عبد الحميد وصالح شاكر وأمل السيد أحمد الظاهر مع الألقاب والصفات والانتماءات المقدمة حرفيًا في `catalog.ts`. لم تُخمن درجة الباحثة. تأثير لون وglow للكروت على hover للماوس،مع احترام reduced motion. البطاقات ليست عناصر تحكم.
- نسخة المحتوى0.4.0-draft وschema1 والتقدم والأسئلة والقواعد محفوظة. أُحدث سجل الأصول لتمييز الأسماء المقدمة عن الأصول المعلقة؛ هذا لا يمنح المحتوى التعليمي اعتمادًا.
- قياس Chromium بعد تحميل خط Cairo: الرئيسية دون سكرول رأسي أو أفقي عند1440×900 و1366×768 و768×1024 و390×844 و360×640 و320×740. قياس الصورة التاريخية1366×768 كان1084بكسل،والجديد768بكسل؛390×844 كان1337والجديد844. الهيدر الواسع123.375بكسل،وروابطه الستة في المنتصف بفارق أقل من بكسل واحد. عند320×568 يبلغ ارتفاع الصفحة664بكسل؛ يحتفظ الهاتف القصير بتمرير طبيعي بدل قص النص أو إخفائه. لا حد ارتفاع ثابت ولا إخفاء overflow للصفحة.
- نجحت مراجعة اللمس وفتح قائمة الهاتف وEscape وعودة التركيز،وقائمة التقويم بالكيبورد،والدخول والخروج من التذييل. تحقق تغير لون وظل الباحثة والمشرفين فعليًا،وتعطيل الانتقال عند reduced motion. فحص axe للصفحة الرئيسية عند1366×768 و360×640:صفر مخالفات ضمن قواعدWCAG A/AA الآلية المختارة،ودون أخطاء JavaScript أو أصول فاشلة بالمقاسات السبعة.
- الأدلة الجديدة منفصلة في `review/compact-home/`:سبع صور مقاسات وصورة hover،وقياساتlayout-results وaccessibility-results وinteraction-results. المعاينة الحالية demo على المنفذ5173 في جهاز التشغيل؛ ليست رابطًا خارجيًا أو إثبات نشر. لم تُمسح أصول أو أدلة المراحل السابقة،ولم تبدأ الخامسة.
