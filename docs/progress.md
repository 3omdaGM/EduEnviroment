## التشغيل والتحقق القابل للإعادة

من `/workspace/EduEnviroment`، باستخدام Node يدعم متطلبات الحزم (على هذه البيئة `24.19.0`):

```sh
npm ci
npm run dev
```

يفتح Vite محليًا على `http://localhost:5173`. هذا عنوان الجهاز الذي يشغل المشروع؛ ليس رابط معاينة مستضافًا يمكن فتحه من جهاز آخر دون forwarding. لم تُستخدم خدمة نشر أو backend.

```sh
npm run typecheck
npm run lint
npm run build
npm run preview
```

البناء ينتج `dist/` ومعاينة البناء على `http://localhost:4173`. الاستضافة الثابتة لاحقًا تحتاج SPA fallback إلى `index.html` لضمان refresh والروابط المباشرة.

بعد البناء، ومن دون تشغيل preview آخر على المنفذ 4173:

```sh
npm run test:e2e
```

يشغّل Playwright معاينة البناء ويوقف خادمه عند النهاية. استُخدم Chromium الموجود في `/usr/bin/chromium` دون تنزيل متصفح جديد؛ لتحديد متصفح آخر اضبط `PLAYWRIGHT_CHROMIUM_EXECUTABLE` على مساره. الاختبارات لا تحتاج API أو حسابات أو اتصالًا بمصادر المحتوى وقت التشغيل.

## نتائج التحقق الفعلية وحدودها

- نجح `typecheck` بوضع strict مع exactOptionalPropertyTypes وnoUncheckedIndexedAccess؛ يشمل كود التطبيق والعقود والاختبارات وإعداداتها. نجح `build` و`lint` دون أخطاء أو تحذيرات lint.
- اجتازت الرحلات 12 اختبارًا في Chromium: خمس شاشات أساسية عند 1366×768 و1440×900 و768×1024 و390×844 و360×640 و320×740؛ لا أخطاء console أو استجابات assets فاشلة في هذه الشاشات، ولا تمرير أفقي.
- نجحت محاكاة اللمس، والكيبورد وEscape واستعادة focus للقوائم وdrawer وحوار تكبير الرسم، وقائمة التقويم، وأجزاء القراءة وإقراراتها، وback/forward وrefresh والأقفال والروابط المباشرة وعلاقة المعرفات و404.
- نجح اختبار نص أطول 18 مرة مع CSS zoom 200% وتغير viewport إلى 360×460، دون clipping أو تمدد أفقي، ونجح reduced motion. هذه محاكاة تكبير CSS وليست ادعاء اختبار زر تكبير متصفح أو لوحة مفاتيح هاتف حقيقية. لا حقول إدخال في هذه المرحلة؛ لم يُختبر ظهور لوحة مفاتيح فعلية.
- فحص axe على الشاشات الخمس الأساسية في مقاسي 1366×768 و360×640 لم يرصد مخالفات WCAG A/AA ضمن القواعد الآلية المختارة؛ لا يحل ذلك محل اختبار قارئ شاشة أو مراجعة إتاحة بشرية كاملة.
- حُفظت 31 صورة (خمس شاشات × ستة أحجام، وصورة النص الطويل عند التكبير) في `review/phase-2/`، وفُحصت الصور بصريًا أثناء العمل. أصلحت المراجعة تباين النص الثانوي وأيقونة التبويب واتجاه عداد التقدم وتغطية التنقل للرسم.
- تقرير الاختبارات `review/phase-2/test-results.json` وتقرير الإتاحة `review/phase-2/axe-results.json`. الصور screenshots للواجهة في Chromium؛ ليست هاتفًا حقيقيًا أو صور محتوى تعليمي.
- بقيت اختبارات المرحلة الأولى التاريخية موثقة في commit السابق: فحص عقود TypeScript 7.0.2 المعزول وأمثلة حدود الدرجات السبعة وتدقيق الوثائق. التطبيق الحالي يستعمل TypeScript 6.0.3 لتوافق أدواته؛ لا ادعاء تشغيل محرك درجات الآن.
