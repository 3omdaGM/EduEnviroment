## ما أُنجز في الثالثة

- استكمال القوالب نفسها لكل الموديولات: **9 دروس (3/2/2/2)،29 عنصرًا،30 جزء قراءة**؛ الأهداف والدليل والاتصال والحسابات والمحاولات تشترك في الهوية والاسم الكامل وRTL. أعداد دروس2–4 وعناوينها مؤقتة ومعلنة في ملف المحتوى.
- دخول وتسجيل واستعادة تجريبية بـReact Hook Form/Zod ورسائل عربية. الاسم مستعار، البريد `@example.com` والرمز المعلن `DEMO`؛ لا حقل كلمة مرور ولا بريد/رمز في التخزين. الاستعادة تصرح بعدم إرسال بريد، والخروج يحفظ تقدم المتصفح.
- `TrainingPort` وحد تنفيذ صغير و`DemoAdapter` محلي، وتحقق Zod من schema1 ونسخة المحتوى والمحاولات والمكافآت. قواعد المجال مستقلة عن React وتُفحص عند كل أمر، والحراسة تطبق على الأزرار والروابط المباشرة والعودة/التحميل.
- حفظ أجزاء القراءة والإجابات وموضع السؤال والمسودات والنتائج تحت `edu-training-demo:v1`. فشل الكتابة لا يعلن حفظًا أو يفتح خطوة؛ فساد/اختلاف النسخة لا يُحذف تلقائيًا، وreset مؤكد داخل أدوات العرض فقط. تغيير نافذة أخرى يكشف عبر baseline وstorage event؛ هذا ليس مزامنة أو معاملة خادم ذرية.
- محرك مشترك: تعليمات ثم سؤال واحد ثم مراجعة وتأكيد ونتيجة وسجل محاولات. **20 قبلي +20 بعدي** بتوزيع15MCQ/5صح وخطأ لكل منهما، وسؤالان للنشاط وسؤالان للذاتي في كل درس: **76 سؤالًا و20 تعريف تقويم**. الترتيب ثابت ولا عشوائية تتغير مع render، والمحاولة المسلمة لا تعدل.
- أول قبلي مُسلّم يحدد أهلية demo: `<=50%` يتيح الأول، والإعادة لا تغيرها. إقرار الأجزاء مرتب ثم نشاط مُسلّم بأي درجة ثم ذاتي `>=50%`، فالتالي حتى البعدي. المقارنات قبل التقريب؛ لا إلغاء لاجتياز سابق بنتيجة أقل.
- XP مستقل:10 للنشاط،20 للدرس،50 للموديول مرة للحدث؛4شارات ومستوى0–4. إكمال المحتوى الكامل470XP، بلا مكافأة قبلي/بعدي أو تعمد انخفاض الدرجة. احتفال عابر لا يتكرر بزيارة/refresh مع احترام reduced motion. البعدي نسبة دون عتبة أو شهادة مخترعة.
- `/demo-tools` خارج رحلة المتدرب: قبل القبلي،مؤهل50،غير مؤهل55،درس غير مجتاز،إكمال البيئة. كل استبدال/reset يحتاج تأكيدًا. Vite يستبدل `__DEMO_TOOLS_ENABLED__` وقت البناء؛ البناء العادي يستبعد route/link وملف الصفحة نفسه.
- المحتوى والأسئلة **draft** بمصادر UNESCO وGoogle وMicrosoft وMendeley وتاريخ الوصول2026-10-16؛ لا اعتماد باحث أو ادعاء تكافؤ بحثي. مراجع Reference Manager وCite منفصلة عن Desktop القديم.

## الملفات والحدود

- `src/data/catalog.ts` و`course-extension.ts` و`assessments.ts`: المحتوى والمعرفات وبنك التقويم والتحرير.
- `src/domain/models.ts` و`training.ts`: عقود التنفيذ المحلي،Zod والقواعد والدرجات والتقدم والمكافآت والتحقق عند الاستعادة.
- `src/services/demo-adapter.ts` و`src/state/TrainingProvider.tsx`: الحفظ والربط. صفحات المتدرب تعتمد الحد المنقح دون localStorage أو مفاتيح مباشرة.
- `src/pages/AccountPage.tsx` و`AssessmentPage.tsx` والقوالب المشتركة و`TrainingGuard.tsx`: الرحلة الفعلية وحالات الخطأ والقفل. أنماط وأصول الثانية محفوظة.
- `src/demo/`: flags وحالات العرض وfixture الاختبار. `src/env.d.ts` و`vite.config.ts` لتعريف شرط البناء. `docs/contracts.ts` يشترك بأنواع المحتوى؛ واجهة TrainingService فيه تبقى تصميمًا مستقبليًا وليست الخدمة المنفذة.
- `src/state/preview.ts` و`tests/phase2.spec.ts` محفوظان تاريخيًا دون تشغيلهما في رحلة/اختبارات الثالثة الحالية. صور وتقارير الثانية في `review/phase-2/` محفوظة كما هي.
- لا Backend/DB أو حساب/بريد حقيقي أو HTTP adapter أو تحليل بيانات دراسة. مفاتيح الأسئلة مكشوفة تقنيًا داخل bundle رغم تنقية كائنات العرض؛ الحراسة المحلية والتحقق من فساد الحالة ليسا أمانًا. البناء الافتراضي يظل demo ولا يصلح وحده لإجراء دراسة محمية.

## التشغيل

من `/workspace/EduEnviroment`،باستخدام Node يلبي `>=22.22.0` (المستخدم هنا24.19.0):

```sh
npm ci
npm run dev
```

Vite على `http://localhost:5173`. هذا عنوان الجهاز المشغّل فقط، وليس رابط معاينة مستضافًا. للدخول استخدم `demo@example.com` ورمز **`DEMO`**؛ أو سجل باسم مستعار. `/demo-tools` متاح في dev.

```sh
npm run build:demo
npm run preview
```

معاينة المحتوى الكامل وأدوات العرض على `http://localhost:4173`. أما `npm run build` فينتج البناء العادي دون أدوات؛ ثم `npm run preview`. الاستضافة الثابتة تحتاج SPA fallback إلى `index.html` للروابط المباشرة. لم تنشر استضافة لهذه المرحلة.

- **20 اختبار Vitest** ناجحًا: حدود القبلي0/50/55/100،الذاتي أقل50/50/100،كسور حول الحد قبل التقريب،أقفال المسار والنشاط بأي درجة،أول قبلي،عدم سحب النجاح أو تكرار XP،immutable/idempotent،الفساد والكتابة والتعارض ومنع حفظ بيانات الدخول،وحجب التغذية للقبلي/البعدي.
