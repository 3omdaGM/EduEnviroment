# تفريغ شعار الجامعة وتنسيق الشعارين

إخفاء الخلفية البيضاء الخارجية لشعار الجامعة في الهيدر الأزرق، مع الحفاظ على الرسم والحروف من الصورة الأصلية. يستخدم CSS قناع العرض `public/images/branding/zagazig-university-mask.svg` المأخوذ من حدود الشعار. ملفا الأصول المقدمان وبصمتاهما كما هما؛ لا صورة مولدة بديلة للشعار أو تغيير لحروفه. القناع مسجل في manifest كأصل عرض مستقل.

مقاس الجامعة 52×52 والكلية 60×52 على الكمبيوتر، و36×36 و40×36 على الهاتف. محاذاة وسطية مع مساحتين متساويتين بجوار العنوان، وobject-fit:contain وإطار خفيف وزوايا ناعمة لصورة الكلية.

نجحت إعادة توليد manifest و28 اختبارًا وlint وtypecheck وبناء demo. الصور والقياسات في verification.json على 4 مقاسات حتى 320×568. تحقق الفحص من تحميل الشعارين والقناع، وعدم تداخلهما مع العنوان أو التمرير الأفقي. مراجعة Chromium ومحاكاة أبعاد، لا أجهزة فعلية. لا تغيير للمحتوى أو التقدم أو قواعد التنقل الحر.
