# مراجعة العرض المضغوط والاختيارات الأربعة

طلب المستخدم تقليل التمرير في الدليل وبقية الصفحات حيث يمكن،ومراجعة الهاتف،وأربعة بدائل لكل اختيار من متعدد بتكوين2×2:أ/ب يمينًا وج/د يسارًا.

التغييرات:هيدر وعناوين ومسافات أصغر؛دليل كامل بتسع خطوات وقائمة اختيار أصلية على الهاتف؛شاشة سؤال مركزة؛النماذج أكثر اختصارًا؛تفاصيل الحفظ والمحاولات والمراجع وتصحيح النشاط/الذاتي وتفاصيل تقدم الموديولات قابلة للفتح. المحتوى التعليمي والأسئلة كاملة،ولا إخفاء overflow للصفحة أو قص النص. شروط الفتح والمكافآت لم تتغير.

## القياسات الفعلية

- ثمانية مقاسات:1920×910،1366×768،1280×620،768×1024،390×844،360×640،320×740،320×568.
- خطوات الدليل التسع في المقاسات الثمانية:72حالة دون تمرير رأسي أو أفقي؛مراجعة النص الكامل والتنقل المباشر/السابق/التالي/التحديث.
- 76سؤالًا عبر20تعريف تقويم في1366×768 و390×844 و360×640:228عرضًا. كل66MCQ بأربعة بدائل مختلفة مرتبة هندسيًا في العمودين،و10صح/خطأ ببديلين. حفظ الاختيار واستعادته بعد التحديث ناجحان. جميع الأسئلة تلائم ارتفاع1366×768 و390×844 دون تمرير. عند360×640 تبقى66شاشة سؤال بحاجة لتمرير طبيعي،وأقصى ارتفاع727بكسل؛لم تُصغّر النصوص أكثر أو تُقص.
- لا تمرير أفقي في الصفحات العامة وصفحات التعلم والاختبارات المقاسة. تبقى قراءة النصوص الطويلة وفهرس المحتوى وبعض النماذج على الهاتف القصير بحاجة لتمرير طبيعي؛قياس كل صفحة فيlayout-*.json. فتح التفاصيل أو ظهور أخطاء النماذج أو التكبير قد يزيد الارتفاع.
- تباين الأرقام المصغرة أُصلح. فحوصWCAG A/AA المختارة عبرaxe في10حالات (login/register/pre instructions/lesson intro/content على الكمبيوتر والهاتف) دون مخالفات،فيregression/axe-results.json. فحوص اللمس ولوحة المفاتيح وعودة التركيز وتكبير النص وتقليل الحركة وفشل الحفظ ناجحة.
- Chromium مع محاكاة أحجام/لمس؛ليست أجهزة فعلية أو مراجعة قارئ شاشة أو اختبارSafari/iOS.

## إعادة التحقق

```sh
npm run lint
npm run typecheck
npm test
npm run build:demo
npm run test:compact
npm run test:compact:regression
npm run build:e2e
npm run test:compact:journey
npm run build
npm run test:compact:production
npm run build:demo
```

الأدوات الثلاثة تستخدم4175/4176/4177ومجلدات آثار منفصلة،ولا تستبدل صور المراحل السابقة. تشغيل اختباراتdemo وe2e أوproduction يكون بعد البناء المناسب،ولا يعاد البناء أثناء تشغيل اختبارات علىdist. الصور وملخص القياسات وتقاريرJSON هنا؛node_modules وdist وآثار الفشل غير مرفوعة.

نسخة الأسئلة0.4.1-draft لأن البدائل تغيرت. بيانات0.4.0/0.3 لا تمحى أو ترحل خفية؛للتجربة الجديدة استخدم ملف متصفح منفصلًا/نافذة خاصة أوreset مؤكدًا في أدواتdemo. المفاتيح والمحتوى ما زالاdraft،ولا Backend/DB أو مرحلة خامسة أو merge تلقائي.
