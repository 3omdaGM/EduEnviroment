# مراجعة الهيدر والرئيسية المختصرين

تعديل واجهة بعد حفظ المرحلة الرابعة؛ الأسماء والصفات من رسالة المستخدم،والمحتوى التعليمي يبقى0.4.0-draft. صور المراحل السابقة محفوظة.

فحص Chromium المحلي عبر Playwright وCairo بعد اكتمال تحميله،2026-10-16. الهواتف محاكاة viewport/لمس وليست أجهزة فعلية. القياسات في `layout-results.json`،وتحقق التفاعل في `interaction-results.json`،وفحص axe المختار WCAG A/AA في `accessibility-results.json`.

| المقاس | ارتفاع الصفحة بعد التعديل | تمرير رأسي |
| --- | --- | --- |
| 1440×900 | 900 | لا |
| 1366×768 | 768 | لا |
| 768×1024 | 1024 | لا |
| 390×844 | 844 | لا |
| 360×640 | 640 | لا |
| 320×740 | 740 | لا |
| 320×568 | 664 | نعم،96بكسل |

لا تمرير أفقي في هذه المقاسات. لا قص للعنوان الكامل أو أسماء الفريق أو الصفات،ولا إخفاء overflow أو تصغير الصفحة آليًا. يبقى التمرير الطبيعي للشاشات الأقصر وعند التكبير. مقارنة الصورة السابقة:1366×768 كان ارتفاعها1084بكسل،و390×844 كان1337.

نجح توسيط خيارات الهيدر الستة،والتحقق من عدم وجود النص الزائد أو رسم الرئيسية،وhover للباحثة والمشرفين وreduced motion،وقائمة التقويم بالكيبورد وقائمة الهاتف باللمس وEscape وعودة التركيز،والدخول والخروج من التذييل. صفر مخالفات axe المختارة في1366×768 و360×640،وصفر أخطاءJavaScript أو أصول فاشلة في القياسات السبعة.

نجحت فحوص النوع والأسلوب و24اختبارVitest والبناء العادي وبناءdemo. اختبار البناء العادي القائم لاستبعاد أدوات العرض ومنع تجاوز قفل المحتوى نجح؛ تقريره المنفصل `production-results.json`. لم تُكرر رحلة التدريب الكاملة لهذا التعديل البصري؛ أدلة المراحل السابقة محفوظة.
