# فتح أهداف الدرس بضغطة واحدة

بعد اختيار عنوان أي درس من قائمة الموديول، تفتح أقسامه وتظهر أهدافه مباشرة. اختيار عنوان الدرس الحالي من المحتوى يعيد الأهداف؛ اختياره في الأهداف نفسها يبقيه مفتوحًا دون تكرار سجل الرجوع. على الهاتف تغلق قائمة الدروس بعد الاختيار لتظهر الأهداف، وتعرض الأقسام المختارة عند إعادة فتح القائمة.

نجحت `npm run build:demo` بما فيه typecheck، وlint، و55 اختبار وحدة. نجحت اختبارات `npm run test:lesson-entry` الأربعة: جميع الدروس الستة عشر في الموديولات الأربعة على الكمبيوتر وعلى هاتف بمحاكاة اللمس، وEnter وSpace، وإعادة اختيار الدرس، وسجل الرجوع وإعادة التحميل، وحراسة الدخول. قارنت اختبارات التنقل بيانات CourseLab وبيانات النسخة السابقة قبل التنقل وبعده وبقيتا مطابقتين.

الصور والتقرير المجاور من Chromium بمحاكاة 1366×768 و390×844؛ لا ادعاء تجربة أجهزة فعلية. لم يتغير المحتوى أو الأسئلة أو قواعد الحفظ أو التصميم. بقي تحذير Vite المعروف عن حجم حزمة JS فوق 500kB دون فشل بناء. لا merge تلقائي.
