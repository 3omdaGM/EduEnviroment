# مراجعة التنقل الحر والأهداف العامة

آخر تحديث: 2026-10-18. الأهداف العامة من صورة المستخدم فقط؛ أكد إبقاء الموديولات القائمة وقبول التمرير الطبيعي عند الضرورة.

- خلفية أزرق لبني وكروت بيضاء، وأهداف عامة ظاهرة كاملة دون كشف أهداف الموديولات.
- إلغاء التقسيم التلقائي للمحتوى وأسماء المشرفين. الدليل بأرقام الخطوات مع إرشاد، وأجزاء القراءة تختار بعناوينها دون أزرار تسلسل.
- التأهل بأول قبلي مُسلّم <=50% يفتح كل الموديولات والدروس والعناصر والأجزاء والأنشطة والذاتي والبعدي. الإنجاز والنقاط مستقلان عن الإتاحة ولا يتكرران.
- القبلي يقبل صفر إجابات، والبعدي يحتاج5، والتقويم الأقصر جميع أسئلته. السابق/التالي/تسليم داخل أسئلة التقويم فقط؛ تأكيد دائم وتحذير للمتروك واحتسابه بصفر. لا مراجعة قبل التسليم، والرابط القديم يعود للأسئلة.

## التحقق

نجحت إعادة توليدmanifest وlint وtypecheck و28اختبارVitest. نجح13اختبارواجهة بالجولة الأساسية،ثم فحصان مركزان أحدهما إعادة1280×620 بعد جعل شبكة العناصر3أعمدة في الكمبيوتر القصير،والآخر فحص الدقة العالية واللمس. نجح اختبار إنتاج إضافي:15اختبارواجهة مميزًا،ولا إخفاقات في التقارير النهائية.

الملفات `test-results.json` و`focused-results.json` و`production-results.json` تحتوي النتائج، و`verification-summary.json` يجمعها دون احتساب الإعادة كاختبار جديد. ملفlayoutلكل حجم يقيس62مسارًا،مع434عرضًا في المجموع. فُحصت النصوص الأصلية للأجزاء58على7مقاسات،وخطوات الدليل التسع علىكل مقاس،وجميع أسماء المشرفين حتى3840عرضًا. نجح تسليم قبلي فارغ وحفظ0/20واستعادته وفتح آخر درس،وحدالبعدي4/5وتحذير15متروكًا وحفظ5/20،وحدالتقويم القصير وفتح درس آخر بعد0%. نجحت فحوصaxe المختارة،واللمس وأرقام الدليل وأهداف الصورة واستبعاد أدوات العرض من البناء العادي. أعيدbuild:demo.

## إعادة الفحص

`npm run content:manifest && npm test && npm run lint && npm run build:demo && npm run test:open-learning`

`npm run build && npm run test:open-learning:production && npm run build:demo`

يحافظ التعديل على نسخة المحتوى0.4.1-draft والأسئلة ومفاتيحها وأوزانها والتقدم المتوافق دونreset. الأدلة السابقة محفوظة،ولاBackend أو مرحلة خامسة.
