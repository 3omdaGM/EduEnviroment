# استعراض الموديولات والتسليم الجزئي والصفحات المتجاوبة

أصبح فهرس المحتوى مختصرًا، مع انتقال خلفية بلون خفيف وglow دون حركة الكارت. الضغط يفتح صفحات الموديول القائمة: المقدمة والأهداف وأسماء وعدد الدروس متاحة قبل التأهل، أما فتح الدرس فيعرض الشروط والخطوة المتاحة. الاستعراض لا يكتب تقدمًا أو يمنح نقاطًا.

## التسليم

أكد المستخدم: القبلي والبعدي يحتاجان 5 إجابات على الأقل، والتقويم الأقصر يحتاج كل أسئلته؛ النشاط والذاتي الحاليان سؤالان لكل منهما. زر تسليم من أي سؤال ينقل إلى التأكيد. إذا بقيت أسئلة، تظهر رسالة عددها واحتسابها غير صحيحة مع نعم أو العودة للمراجعة. الدرجة من جميع أوزان الأسئلة: 5 إجابات صحيحة و15 متروكة = 5/20 = 25%، و5 خاطئة و15 متروكة = 0/20. لا تسليم تحت الحد أو إعلان حفظ كاذب، ولا تعديل للمسلّم أو تكرار مكافآت. الشرط في domain وفي استعادة الحالة أيضًا.

لم تتغير الأسئلة أو مفاتيحها أو ترتيبها أو مصادرها، ولا قواعد الأهلية والاجتياز أو XP. بقيت النسخة 0.4.1-draft، والحالات الكاملة المحفوظة لهذه النسخة متوافقة دون reset. تعريفات التقويم وسجل التحرير والعقود تسجل الحد الأدنى بدل ادعاء اشتراط جميع الإجابات في القبلي والبعدي.

## الاستجابة وتقليل التمرير

- FitPages يعرض القوائم والأهداف والنصوص الطويلة في صفحات بالتالي/السابق، مع قياس فائض الارتفاع. على الهاتف القصير يقسم الفقرة عند حدود الكلمات دون حذف النص. الفحص يزور صفحات النص ويقارنها بالنص الأصلي كاملًا.
- معلومات الحفظ وسجل المحاولات والمراجع والتصحيح وتقدم المسار في نوافذ مستقلة مع صفحات عند الحاجة. رسالة القفل تظهر مباشرة دون تكرار تعليمات التقويم فوقها. النتائج والمراجعة والتأكيد أكثر اختصارًا أيضًا.
- على الهاتف أو الشاشة القصيرة يكون عنوان الموديول/الدرس الكامل والتنقل من زر «أقسام الدرس/الموديول»، مع h1 لقارئ الشاشة. على الهاتف القصير أثناء الامتحان يحافظ الهيدر على الاسم الكامل والشعارين، ويضع القائمة تحت الشعار الأيسر. توجد أدوات الجلسة في القائمة بدل تذييل إضافي. الأزرار الأساسية تبقى متاحة.
- ثمانية مقاسات:1920×910،1366×768،1280×620،768×1024،390×844،360×640،320×740،320×568. لا إخفاء overflow للصفحة أو قص نص تعليمي. إخفاء عنوان التنقل البصري أو قائمة مراجعة مكررة يكون مع بديل مكافئ متاح: قائمة الأقسام أو اختيار السؤال الأصلي.
- القياسات تشمل الفهرس والاستعراض قبل التأهل وبعده وقفل الدروس، والصفحات العامة وخطوات الدليل التسع، وأقسام الدروس التسعة وأجزاء القراءة الـ58، والأسئلة الـ76 على أربعة مقاسات حتى320×568، وشاشات المراجعة والتأكيد والنتائج والتصحيح.
- الصور viewport؛ تصوير fullPage قد يغير viewport مؤقتًا ويعيد حساب الصفحات. ملفات layout/public/reading/questions/exam-stages تسجل القياسات الفعلية، مع زيارة صفحات القوائم والنصوص. الصور والتقارير السابقة محفوظة خارج هذه الجولة.

عدم التمرير مثبت للحالات والمقاسات المقاسة، وليس وعدًا لكل ارتفاع ممكن. قد يلزم تمرير عند تكبير النص أو ظهور أخطاء نماذج متعددة أو لوحة المفاتيح أو ارتفاع أصغر؛ لا تُخفى الرسائل أو يُقص النص لمنعه. الفحص Chromium ومحاكاة أحجام ولمس، وليس أجهزة فعلية أو Safari أو قارئ شاشة بشري.
