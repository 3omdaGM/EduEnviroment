# مراجعة كروت أهداف البيئة

صفحة`/goals` بأربع كروت2×2. تظهر الأسماء أولًا؛hover بالماوس يعرض الأهداف مؤقتًا،والضغط يثبتها داخل الكارت مع بروز وglow وانتقال220ms. لا قسم تفاصيل تحت الشبكة. في العرض الضيق/القصير يتمدد المفتوح داخل مساحة الشبكة نفسها ويعطل التركيز على الكروت المغطاة. زر الإغلاق وEscape يعيدان التركيز،وEnter/Space يعملان،وتقليل الحركة يلغي الحركة.

الفحص:Chromium عبرPlaywright،2026-10-16،بعد تحميلCairo. الهاتف محاكاةviewport/لمس وليس جهازًا فعليًا. التشغيل:`npm run build:demo` ثم`npm run test:goals`؛تقريرtest-results مستقل عن تقارير المراحل السابقة،وآثار الإخفاق المؤقتة مستثناة منGit.

نجحت الاختبارات الثمانية:قياسdocument.scrollHeight/scrollWidth وscrollY،وحدود الكروت والنصوص دون قص أو تداخل مع العناوين،والعرض2×2،وhover/الضغط/التثبيت والإغلاق والكيبورد واللمس وreduced motion. تحققت أهداف الموديولات الأربعة والروابط المباشرة وreload و404،وثبات بايتاتlocalStorage وبقاء محتوى التدريب مقفلًا بعد الاطلاع. صفر أخطاءJavaScript أو أصول فاشلة.

فحصaxe ضمنWCAG A/AA المختارة للمقاس1366×768 و360×640 في الحالتين المقفولة والمفتوحة:صفر مخالفات. تفاصيل القياس والفحص فيlayout-*.json،و16صورة للحالتين في المقاسات الثمانية. لا إخفاءoverflow للصفحة أو قص نص لتقليل السكرول؛ عند التكبير أو شاشات أصغر من المقاسات المفحوصة يبقى التدفق الطبيعي. لا تغيير للبيانات التعليمية أو النسخة أو شروط الأهلية.

نجحتlint وtypecheck و24اختبارVitest والبناء العادي واختباره لاستبعاد أدوات العرض ومنع تجاوز القفل،ثم أُعيدbuild:demo. تقرير البناء العادي فيproduction-results.json. لم يُكرر اختبار الرحلة التعليمية الكاملة لهذا التعديل؛تتحقق اختبارات الأهداف نفسها من ثبات التخزين وبقاء القفل.
