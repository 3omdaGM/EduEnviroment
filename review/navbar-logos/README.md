# مراجعة الشعارين في الهيدر

الطلب: استكمال شعار الجامعة وشعار الكلية من الملف المرفق،مع إبقاء المقدمة والإطار وتوسيط التنقل. ملفا `zagUni.jpg` و`تربية+نوعية.png` من `انفوجرافيك للبرامج.rar` منسوخان دون قص أو إعادة ترميز. المصدر والبصمات في `public/images/branding/README.md` و`src/data/branding.ts` والـmanifest؛asset-integrity.json يثبت تطابق الملفات المصدرية والمبنية مع ملفات الأرشيف.

مراجعةChromium عبرPlaywright بتاريخ2026-10-16 بعد تحميلCairo والصور،مع محاكاة لمس للهاتف وليست أجهزة فعلية. كل صورة لهاalt واضح وأبعاد أصلية صريحة،وتُعرض كاملة بـobject-fit:contain داخل52×52واسعًا و32×32على الهاتف. تؤكدlayout-results الأبعاد الطبيعية148×148 و620×539 وتحميل الشعارين،دون أخطاءJavaScript أو أصول فاشلة أو تمرير أفقي. التوسيط والإطار وترتيب المقدمة قبل الباحثة محفوظون.

القياسات مطابقة لما قبل إضافة الشعارين؛ لا زيادة في السكرول. تظل الشاشات القصيرة تحتاج التمرير الطبيعي للنص الكامل كما في مراجعةالمقدمة. لا قص أو إخفاءoverflow.

نجحت مراجعة اللمس وقائمة الهاتف وEscape وعودة التركيز،والتقويم بالكيبورد والدخول والخروج،وhover وتقليل الحركة. صفر مخالفاتaxe ضمنWCAG A/AA المختارة عند1366×768 و360×640. نجحتcontent:manifest وlint وtypecheck و24اختبارVitest والبناء العادي واختباره لاستبعاد أدوات العرض،ثم أُعيد بناءdemo. لا إعادة لرحلة التدريب الكاملة؛ قواعد التدريب لم تتغير. صور المقاسات السبعة وصورةhover منفصلة عن أدلة المراجعات السابقة.
